## 二、P0 修复（体检报告中标记为"必修"的 7 项）

### 1. 删除脚手架残留样式，重建全局样式与布局 —— UI 丑的根因

**问题**：`src/style.css` 是 Vite 脚手架的 demo 样式，其中 `#app { width: 1126px; text-align: center; border-inline: 1px solid }` 正在破坏整个布局——把全屏布局压在 1126px 宽、全局文字居中、左右加两条竖线。文件里 `.hero`、`#next-steps`、`.ticks` 等样式**没有任何一条被业务代码引用**。

**改动**：
- 删除 `src/style.css`
- 新建 `src/styles/theme.css`：设计令牌（色板/间距/字体/圆角/阴影）+ 全局重置 + Element Plus 深色变量覆盖

**新增设计令牌体系**（全站唯一色源，业务组件不再硬编码颜色）：

| 用途 | 变量 | 值 |
|---|---|---|
| 页面底色 | `--bg-base` | `#080b12` |
| 面板 | `--bg-panel` | `#10151f` |
| 主强调（草皮绿） | `--c-accent` | `#00e07a` |
| 次强调（琥珀金） | `--c-gold` | `#f2b73d` |
| 信息蓝 / 告警红 | `--c-info` / `--c-danger` | `#3aa0ff` / `#ff5c6c` |

### 2. 修复详情页切换球员不刷新的真 Bug

**问题**：`PlayerDetailView.vue` 中 `const playerName = decodeURIComponent(route.params.name)` 只在 `onMounted` 求值一次。路由 `/players/:name` 前后是同一个组件实例，Vue 会复用它，因此从"球员 A"跳到"球员 B"时 **URL 变了但页面数据不变**。

**改动**：`playerName` 改为 `computed`，取数逻辑抽成 `load()`，用 `watch(playerName, load, { immediate: true })` 驱动。

### 3. 修复 `.toFixed()` 空值崩溃（5 处）

**问题**：Python 的 `json_safe()` 会把 NaN/Inf 转成 JSON `null`（已实测确认），而前端多个视图直接写 `row.score.toFixed(2)`。任一球员评分为 `null` 就会抛 `TypeError`，整张表格白屏。

**改动**：新建 `src/utils/format.js`，提供 `fmt` / `fmtScore` / `fmtInt` / `fmtRatio` / `fmtDiff` / `scoreColor` / `positionLabel` / `flagUrl`，全部内置空值保护并返回 `—` 占位符。**全部视图改为使用这些函数，源码中不再存在裸 `.toFixed()`。**

### 4. 修复表格前后端排序冲突

**问题**：`PlayersView` 已把排序交给后端（`order` + `direction` 参数），但列上又写了 `sortable` —— Element Plus 的 `sortable` 是**纯前端排序，只排当前页的 20 条**，用户点列头得到的是"第 1 页 20 人内排序"，结果错误且无任何提示。`RankingsView` 更糟：列没有 `prop` 却写了 `:sort-by="'score'"`。

**改动**：移除全部 `sortable`，排序统一走后端；新增 `ASC_IS_BETTER` 集合让"年龄"等字段的升序方向语义正确。

### 5. 错误不再被静默吞掉

**问题**：7 个视图中几乎每个请求都是 `catch (e) { console.error(e) }`，页面上什么都不显示。Python 服务没启动时，用户看到转圈结束后的一片空白。

**改动**：
- 新建 `components/ErrorState.vue`：错误占位 + 原因 + 排查提示 + 重试按钮
- 各视图统一使用，并在 `request.js` 中区分三类错误：业务错误（后端返回 code/message）、HTTP 错误、网络错误
- `request.js` 保留并展示后端原始 message，不再统一替换成"网络错误"

### 6. 补 404 兜底路由 + 页面标题

**改动**：新增 `/:pathMatch(.*)*` 兜底路由与 `NotFoundView.vue`；`router.afterEach` 写入 `document.title`（原先路由里定义了 `meta.title` 但从未被使用）；`index.html` 改 `lang="zh-CN"` 与正确标题。

### 7. 清理脚手架残留文件

删除：`HelloWorld.vue`、`hero.png`、`vite.svg`、`vue.svg`、`style.css`（共 5 项，全部无引用）。

## 三、P1 完成项

### 8. 后端健壮性（体检报告 B1–B5）

| 项 | 改动 |
|---|---|
| **无超时**（会耗尽 Tomcat 线程池导致服务假死） | `HttpClientConfig`：连接 5s / 读取 30s |
| **无异常处理**（Python 挂掉返回 HTML 白页） | 新增 `GlobalExceptionHandler` + 两个自定义异常 |
| **地址硬编码** | `PythonApiProperties` 读取 `python.api.base-url` |
| **Content-Type 不受控** | 全部改为 `ResponseEntity<String>` 显式声明 `application/json` |
| **老旧 API** | `RestTemplate` → `RestClient`（Spring Boot 4 推荐） |

**同时修复的接口缺口**：`/api/players/{name}` 原先不透传查询参数，导致 Python 侧支持的 `similar_n`（相似球员数量）无法传入，现已透传。

**本轮续查追加修复的异常缺口**：验收时实测发现，访问**不存在的接口路径**返回的是
`500 后端服务内部错误：NoResourceFoundException`，用错误方法请求返回 500 —— 原因是
最初的 `Exception.class` 兜底把 Spring 自身的 `NoResourceFoundException`、
`HttpRequestMethodNotSupportedException` 一并吞掉了，把"路径写错了"误报成"服务端故障"。
已补充三个精确处理器：

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 不存在的接口 `GET /api/nonexistent` | 500 `NoResourceFoundException` | **404** `接口不存在：GET /api/nonexistent` |
| 错误方法 `POST /api/health` | 500 | **405** `接口不支持 POST 方法` |
| 球员不存在 `GET /api/players/NoSuchGuy` | 404（正常） | 404（保持） |

**实测验证**（停掉 Python 后）：

```
HTTP/1.1 503
Content-Type: application/json

{"code":503,"message":"分析服务暂时不可用，请确认 Python 服务已启动（默认 127.0.0.1:5000）","data":null}
```

改造前：Spring 默认 HTML 错误页 → 前端只能显示"网络错误"。

### 10. 修复深色模式

原先 `style.css` 有 `prefers-color-scheme: dark` 媒体查询会把背景改黑，但**没有引入 Element Plus 深色主题**，导致深色系统用户看到"深色底 + 浅色组件"的诡异混搭。现已在 `main.js` 引入 `dark/css-vars.css` 并设置 `html.dark`。

### 11. 评分预测页可用性改造（体检报告 F14）

这是原项目**最大的可用性问题**——用户不知道该填 0.5 还是 50。

- 每个指标标注**单位 + 参考范围 + 权重**（如"进球 · 球/90分钟 · 顶级前锋约 0.6–1.0 · 权重 25%"）
- 门将的百分比尺度指标（`SavePct` 等）额外显示「百分比尺度」警告标签，避免误填 0.725
- 前端按范围预校验，超范围给出明确提示而不是把请求发给模型
- 新增「填入示例数据」一键体验（示例值实测可得到 87.8 分，可信）
- 预测结果新增**同位置百分位换算** + 群体分布直方图 + 预测值标线 + 水平评语
- 新增模型评估全貌：R² / RMSE / MAE / 5 折交叉验证 / 训练样本
- 新增**特征重要性**横向条形图（源自原先闲置的 `/api/model.importance`）
- 新增**测试集预测 vs 实际**散点图 + y=x 参考线

### 12. 新增相似球员探索页（启用闲置接口）

体检发现 `/api/similar` 后端有、前端完全没调用。新增 `SimilarView.vue`：
- 远程联想选球员，可限定位置或跨位置检索
- 「相似度 × 综合评分」二维散点图（点越靠右上 = 又像又强）
- 完整相似球员明细表（相似度进度条按阈值着色）

### 13. 分页器与响应式

- 分页补 `page-sizes` 选择器与跳页（原先 `page_size` 是只读绑定，界面上根本改不了每页条数）
- 侧边栏可折叠 + 移动端抽屉式导航
- 全部栅格补 `:xs` / `:lg` 断点，KPI 网格 4→2→1 列自适应

### 14. 修复 Vite 只监听 IPv6 的隐患

实测发现 Vite 只绑定在 `::1` 上，`http://127.0.0.1:5173` 连接被拒（Node 17+ 下 `localhost` 可能只解析到 IPv6）。已在 `vite.config.js` 显式设置 `host: '127.0.0.1'`。
